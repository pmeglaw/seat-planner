What Carbon v12 will be — and what it does to the Seat Planner

Carbon v11 is at v11.11x and IBM has begun shipping v12's delivery mechanisms. This brief predicts v12 from what IBM has actually committed — the enable-v12-* feature flags, the published upgrade codemods, and the Carbon for AI program — and maps each prediction onto the redesign concepts. Baseline: current UI recreation.

THE ONE-LINE PREDICTION

v12 is a structural release, not a rebrand — the Layer model everywhere, Menu-unified popovers, a denser size ramp, and the AI decorator as a first-class slot on every component. IBM Plex, flat/square, the 2x grid: unchanged.

WHY CONSERVATIVE IS CORRECT

IBM's own release policy: every v12 breaking change ships as a flag inside v11 first, and a project with all flags enabled upgrades with no changes. The next major is, by design, already visible.

The evidence

Everything below is public and committed — flag names are verbatim from the Carbon monorepo and the @carbon/upgrade codemods.

enable-v12-overflowmenu

OverflowMenu is rebuilt on the shared Menu subsystem — MenuItem label / kind="danger" replaces OverflowMenuItem. One menu anatomy everywhere: icons, shortcuts, dividers, danger items.

enable-v12-tile-default-icons

Tiles ship with default icons — clickable, selectable and expandable tiles carry their action glyph out of the box instead of leaving affordance to chance.

slug → decorator

The codemod renames the AI-label slug prop to decorator across components — the AI label becomes a standardized slot on inputs, tags, modals, tables. AI presence is component infrastructure now.

Button light → Layer

Per-component light props are deleted; surfaces come from wrapping in <Layer>. Elevation becomes a declared, inherited system — layer-00/01/02 — not a per-widget switch.

enable-v12-toggle-reduced-label-spacing

Label-to-control spacing tightens (spacing-05 → spacing-03). Together with new xs field sizes, sm line tabs and condensed vertical tabs in recent minors, the ramp is clearly moving denser.

feat(v12): code path delivery

"Set up v12 code path delivery mechanisms" landed in the monorepo (June 2026), alongside React 16/17 deprecation warnings and TypeScript 6 — the release machinery is being built now.

COMMITTED

The white-label rule

Brand stays firm orange

Publish now rides the deep CTA #D23F0A with a white label (owner pick, 2a); the bright #FF5715 keeps the indicator jobs — active underline, selected seat, search highlight — where it never carries text. Carbon blue is swapped out exactly as today.

AI keeps Carbon's reserved blue-light

AI presence is system identity, not brand identity: it must never read as a status hue or the accent. The app's dark chrome already uses this blue family for info text, so it is not a new hue — it is a promoted one.

Status discipline unchanged

Three status hues + IBM gray ramp + one accent — the palette consolidation the repo already fought for holds under v12. Seat pills are untouched (protected anchor + owner-locked look).
