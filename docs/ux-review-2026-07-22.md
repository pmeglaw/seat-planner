## 6. Where Option C (markers) + recalibration actually sit

Option C targets **occupancy legibility** — but #187 already shipped the non-color status shape (#1) and render-layer collision nudges (#4/#14). So the marginal gain from a full density-adaptive marker rebuild is **smaller than it looked**, while it's the **highest-effort, highest-risk** item (touches the protected marker + its guardrail test + calibration).

Recommendation:
1. Do **P1 viewer fixes** first — cheap, certain, broad audience.
2. Run the **[LIVE] pass** (§5). It directly measures whether legibility is actually still broken at real breakpoints.
3. **Only if L1/L2 show pills still collide/occlude** does Option C's zoom-tiering earn its cost — and then you implement it with evidence, not on spec.
4. **Recalibration** is chair-fit tuning, not a top user-facing finding; do it opportunistically (or when you touch an area), not as a headline.

Net: the Fable 5 marker/recalibration hand-off isn't wrong, it's **mis-ordered**. This review moves it behind the viewer work and the live check.
